# SIVADARSH — GitHub portfolio

This is a self-contained, motion-led portfolio for Sivadarsh. It preserves the composition, typography, loader, transitions, horizontal gallery, and responsive behavior of the supplied visual reference while rebuilding the identity and content around the public [GP-commits GitHub profile](https://github.com/GP-commits).

The featured work and imagery come from original public repositories, including Git-Secrets, OpenClassCraft, Smart Campus, Kivy-Python, FocusGram, Focus with Lo-Fi, Clash of CUSAT, Code-A-Pookalam, Make-A-Ton, and Koode.

## Run locally

```bash
npm start
```

Then open <http://127.0.0.1:4173/>.

No dependency installation is required. The project assets, fonts, animation libraries, and Webflow runtime used by the page are stored in this directory so the main experience can run locally.

Portfolio adaptation, visual direction, development, and typography direction are credited to Sivadarsh.
